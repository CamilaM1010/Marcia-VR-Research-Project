# Classroom-Anomaly
- Uses Unity 6

## DEV SCENE COMMITS:

- Make prefabs out of your stuff when possible (e.g., UI is a prefab, each NPC is a prefab, the Student's VR Rig is a prefab, etc).

### Individual Scene/Branch changes:

- Steps to Commit:
    - Ensure your changes are complete and ready to be committed.
    - Save all in the editor.
    - CLOSE THE EDITOR.
    - Fetch all, from your branch and dev.
    - Consistently check if pushes to dev have been made (switch to dev and fetch all). If so, **merge dev into your branch**
        - You want to make sure that your branch is up-to-date with everyone's latest changes!
    - Commit to your branch. Do not push.
    - In the case of merge conflicts, kept changes should come from your branch and scene.
    - Make sure you are committing the most-updated PRE-FABs (override).
    - Push to your branch!
- If your pre-fab(s) is(are) already in dev scene:
    - Switch to dev, and merge your branch into dev.
    - Push to dev.
- If your pre-fab(s) has(have) not been placed in dev scene:
    - Switch to dev after pushing your branch.
    - Merge your branch to dev and **push**!
        - If there are merge conflicts, keep the version from **your branch**.
        - If you aren't sure what to do, message the @Marcia role on Discord.
    - Place your pre-fabs INTO THE *HIERARCHY* on dev branch in Assets->Scenes->Classroom scene.
    - Save in the editor.
    - Close the editor.
    - Ensure you're on dev branch.
    - Commit.
    - PUSH!!
 
NOTIFY THE @MARCIA ROLE ON DISCORD WHEN YOU PUSH TO DEV.
